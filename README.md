## 📚 Course 1: Foundations of Cybersecurity
**Status:** Completed (October 2026) 🎓

This foundational course introduced the core concepts of the cybersecurity landscape, the ethical responsibilities of security professionals, and the primary tools used to mitigate risk and protect data.

### 🔑 Core Competencies Mastered
* **Security Frameworks & Ethics:** 
  * Understanding the **CIA Triad** (Confidentiality, Integrity, Availability).
  * Navigating the eight **CISSP Security Domains**.
  * Applying the **NIST Cybersecurity Framework**.
  * Ethical and legal responsibilities regarding Personally Identifiable Information (PII) and Sensitive PII (SPII).
* **The Threat Landscape:** 
  * Identifying threat actor motivations (APTs, hacktivists, insider threats).
  * Analyzing common attack vectors including social engineering, malware, and supply-chain attacks.
* **The Analyst Toolkit:** 
  * Introduction to **SIEM platforms** (Splunk, Google Chronicle) for log analysis.
  * Utilizing network protocol analyzers (packet sniffers) like Wireshark and `tcpdump`.
  * Following Incident Response Playbooks (Chain of Custody, Order of Volatility).
* **Technical Foundations:** 
  * Recognizing the necessity of programming and OS navigation.
  * Introduction to Linux CLI, SQL database queries, and Python for automating defensive security tasks.
